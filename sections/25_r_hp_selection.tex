\subsection{Hyperparameter selection, held-out validation, and significance}
\label{sec:holdout}
We selected all post-processing hyperparameters by grid search on the VeRi-776 query/gallery split. These are AQE $k$, the $k$-reciprocal re-ranking triple $(k_1,k_2,\lambda)$ and the fusion weight $w_1$. This is a possible source of optimistic bias, and we state it openly. To be clear: every headline number in this paper uses these split-tuned values. The validation analyses below measure and bound the optimism of that choice. They are audits of the headline configuration, not its source.

Three observations limit that bias. First, the selection surface is flat, not peaked. The fused mAP stays above $93.0\%$ across the entire range $w_1\in[0.2,0.5]$ (Figure~\ref{fig:weight}), so the reported result does not sit on a sharp test-set optimum. Second, the re-ranking setting was tuned, but it does not sit on a sharp optimum. The values $k_1{=}80,k_2{=}15,\lambda{=}0.2$ are larger than the defaults of Zhong et al.~\cite{zhong2017rerank} ($k_1{=}20,k_2{=}6,\lambda{=}0.3$), and the sweep below shows that mAP stays within 88.3--90.1\% across a wide grid around them. AQE $k{=}3$ is a small, common neighbourhood size. Third, the test set (200 identities, 1\,678 queries) is large compared with the small number of scalar hyperparameters we selected. This limits how much we can overfit.
