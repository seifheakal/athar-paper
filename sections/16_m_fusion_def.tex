\subsection{Score-level fusion}
\label{sec:fusion}
Given post-processed similarity matrices $\mathbf{S}_{\mathrm{ViT}}$ and $\mathbf{S}_{\mathrm{CLIP}}$, the fused similarity is:

\begin{equation}
  \mathbf{S}_{\mathrm{fusion}} =
    w_1\,\mathbf{S}_{\mathrm{ViT}} + w_2\,\mathbf{S}_{\mathrm{CLIP}},
  \quad w_1+w_2=1
  \label{eq:fusion}
\end{equation}

In practice, the fusion pipeline uses the \textbf{1536D} concat-patch flip-TTA Stream~1 representation together with the 2048D Stream~2 representation. The Stream~1 representation is the best-mAP configuration of Section~\ref{sec:method}, not the 768D CLS-only variant. First, we apply AQE with $k{=}3$ to each stream. Then we combine the resulting cosine-similarity matrices with Eq.~\eqref{eq:fusion}. Finally, we apply a single joint $k$-reciprocal re-ranking ($k_1{=}80, k_2{=}15, \lambda{=}0.2$) to the fused matrix. So the fusion uses a common AQE $k{=}3$ for both streams. It does not reuse the standalone settings of Stream~2 (AQE $k{=}10$ and re-ranking $50/10/0.1$). Those settings give only the standalone CLIP-SENet result (91.44\% mAP).

We prefer this order of operations because it works better, as Figure~\ref{fig:order} shows. If we re-rank each stream separately with its standalone parameters and then fuse the distances, we get 92.73\% mAP / 97.68\% Rank-1. This is $0.59$\,pp mAP below the deployed order, which fuses first and then re-ranks jointly (93.32\%\,/\,98.45\%). The joint $k$-reciprocal neighbourhoods use the agreement between the two streams, and per-stream re-ranking throws that away.
