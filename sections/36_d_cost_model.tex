\subsection{Computational cost and deployment}
\label{sec:cost}
Because deployment cost is a first-order concern for intelligent transportation
systems, we make the inference budget explicit and separate it from the
retrieval-accuracy budget.

\paragraph{Model and feature-extraction cost.} A single Stream~1 forward pass
is a ViT-B/16 at $224\times224$ ($\approx$86\,M parameters,
$\approx$17.6\,GFLOPs); Stream~2 (ResNet101-IBN-a $+$ TinyCLIP) is of
comparable order at its $320\times320$ input. The best-mAP Stream~1
configuration uses horizontal-flip TTA, which \emph{doubles} the forward
passes; the concat-patch representation reuses already-computed tokens and adds
negligible compute. The two-stream fusion requires \emph{both} backbones,
roughly doubling extraction time and model memory relative to a single stream.
Measured on a single NVIDIA~T4 (batch~1), a Stream~1 forward is 13.5\,ms/image
at 700\,MB peak VRAM, rising to 27.2\,ms with flip-TTA; Stream~2 is
21.2\,ms/image at 721\,MB; the full two-stream extraction is 48.4\,ms/image
($\approx$21 images/s), matching the expected $\approx$2$\times$ TTA and fusion
multipliers. All of these costs are $\mathcal{O}(N)$ in the number of images
and are trivially parallelisable. Feature storage is modest: 6.1\,kB/image for
Stream~1 (1536D fp32) and 8.2\,kB/image for Stream~2 (2048D), i.e.\ 166\,MB for
the full two-stream VeRi-776 gallery; even the 128{,}517-image VeRi-Wild
10{,}000-protocol gallery fits in 0.79\,GB fp32 (0.39\,GB fp16) for Stream~1.
