\subsection{Stream~2: CLIP-SENet branch}
The CLIP-SENet architecture~\cite{lu2025clipsenet} gives us a second, complementary feature stream. The ViT-B reads images as sequences of global patch tokens with self-attention. CLIP-SENet uses a ResNet101-IBN-a backbone~\cite{pan2018ibn} instead. It applies local convolutional filters with Instance-Batch Normalisation (IBN). This captures fine-grained local texture that is less visible in global attention maps.

CLIP-SENet has three components~\cite{lu2025clipsenet}:
\begin{enumerate}
  \item \textbf{CNN backbone.} ResNet101-IBN-a~\cite{pan2018ibn} gives 2048-dimensional local appearance features. IBN combines instance normalisation (style invariance) with batch normalisation (discriminative learning). This helps cross-camera ReID, where the style of each camera is a nuisance.
  \item \textbf{Semantic Extraction Module (SEM).} The TinyCLIP image encoder extracts a 512-dimensional visual-semantic representation. Unlike CLIP-ReID~\cite{li2023clipreid}, it does not use a text encoder at any stage~\cite{lu2025clipsenet}.
  \item \textbf{Adaptive Fine-Grained Enhancement Module (AFEM).} It groups and weights fine-grained vehicle attributes (model, colour, shape) from TinyCLIP. This gives strong semantic embeddings without text annotations~\cite{lu2025clipsenet}.
\end{enumerate}

The CLIP-SENet v6 checkpoint is trained on VeRi-776 with Adam ($\mathrm{lr}\!=\!5\!\times\!10^{-4}$, wd$=\!5\!\times\!10^{-4}$, cosine schedule), $P\!=\!8$, $K\!=\!8$ and effective batch 128 (\texttt{accum\_steps}=2). The loss is CE-LS $+$ SupCon. It trains for 24 epochs with a 5-epoch warm-up on a P100 GPU ($\approx$4\,h\,26\,min). The input size is $320\!\times\!320$, which matches the released CLIP-SENet~v6 checkpoint. We did not reproduce a $256\!\times\!256$ training-resolution variant in this campaign.
