\paragraph{Post-processing cost.} Post-processing is where the cost concentrates. AQE is a single similarity pass with a top-$k$ average, so it is cheap. In contrast, $k$-reciprocal re-ranking~\cite{zhong2017rerank} is $\mathcal{O}(N^{2})$ in gallery size $N$ (here $N\!\approx\!11.6$\,k), in both time and memory. It is the dominant offline cost. It gives the single largest accuracy step ($+5.55$\,pp mAP on Stream~1), but as written it is unsuitable for low-latency online retrieval. Figure~\ref{fig:cost}a shows the scaling on VeRi-776. A re-ranking pass for a single query set over the full 11.6k gallery takes 50\,s, and the CPU AQE pass takes 138\,s. Both rise steeply as the gallery grows. The sharp CPU-AQE jump between $N{=}8{,}684$ and $N{=}11{,}579$ is a memory-hierarchy effect. The similarity matrix outgrows the cache and BLAS tiling gets worse. It is not an algorithmic effect. The chunked GPU AQE used everywhere else in this paper scales smoothly to $N{=}138{,}517$.

Under domain transfer the picture changes in kind, not only in degree. On the VeRi-Wild probe of Section~\ref{sec:veriwild} (query$+$gallery $=41{,}861$), a re-ranking pass takes 254\,s on CPU. That is about $5\times$ the in-domain pass for $3.2\times$ as many images. It also reduces accuracy on the poorly clustered transfer features ($-1.1$\,pp mAP for ViT-B, $-2.7$\,pp for the fusion, Table~\ref{tab:veriwild}). A further pass at $N{=}69{,}389$ (the 5{,}000-protocol union, with the pairwise-distance state held in fp16 to fit host memory) takes 519\,s. Across the three measured sizes (13{,}257, 41{,}861 and 69{,}389 images), time grows roughly as $N^{1.4}$, below the worst-case $\mathcal{O}(N^{2})$ in this range. Memory, by contrast, grows quadratically. It again reduces accuracy (30.48\%$\rightarrow$29.42\% mAP). Beyond this point the memory wall comes before the time wall. At the VeRi-Wild 10{,}000-identity protocol ($N{=}138{,}517$), the $\mathcal{O}(N^{2})$ pairwise-distance state takes ${\approx}77$\,GB in fp32 (${\approx}38$\,GB even in fp16). This is more than common host memory, so the full-gallery measurement is infeasible for the dense implementation. Chunked GPU AQE, in contrast, ran at every scale. Re-ranking is therefore doubly unattractive for cross-domain retrieval. Its memory grows quadratically and its time super-linearly, and its accuracy benefit is domain-specific. AQE-only post-processing is the sensible transfer configuration, and it is what we headline on VeRi-Wild.
