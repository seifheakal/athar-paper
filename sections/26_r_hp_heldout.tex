To move beyond these a-priori arguments, we ran a disjoint-identity held-out
protocol: the 200 test identities are split into two 100-identity halves, the
fusion weight is selected on the first half (with AQE and re-ranking held at
the standard values above), and the result is reported on the second half with
that weight frozen. The validation half selects $w_1{=}0.25$ whereas the full
test set favours $w_1{=}0.35$; because the weight surface is flat
(Figure~\ref{fig:weight}), this disagreement is almost free---reporting the
full-test result at the validation-selected $w_1{=}0.25$ gives 93.25\% mAP,
only \textbf{0.07\,pp} below the test-tuned 93.32\%. The optimistic bias from
selecting the fusion weight on the evaluation set is therefore
$\lesssim$0.1\,pp and changes no conclusion; with that weight frozen, the
held-out 100-identity split reaches 96.3\% mAP / 99.1\% Rank-1, confirming the
fusion generalises across disjoint identities. The held-out-validation script
is released so readers can reproduce this check.

Because this split still draws its identities from the test set, we add a
second protocol using identities disjoint from the test set entirely: we carve
a 100-identity validation set from the 576 \emph{training} identities and
re-select the fusion weight there. As those images were seen during training,
retrieval on them saturates (mAP $=100\%$ for every $w_1\in[0.2,0.5]$), so the
selection is uninformative in isolation---but freezing the resulting choice
($w_1{=}0.2$) and evaluating on the true test set gives 93.13\% mAP, only
\textbf{0.18\,pp} below the test-tuned 93.32\%. Both protocols thus bound the
evaluation-set weight-selection bias below 0.2\,pp. For a selection-free
configuration out of the box, Table~\ref{tab:oppoints} lists the
validation-selected operating point ($w_1{=}0.25$, literature-default
post-processing) at 93.25\% mAP / 98.15\% Rank-1---the recommended default for
unbiased comparison. A fully unseen validation set---holding identities out of
\emph{training} rather than reusing seen images---would be stricter but
requires retraining, which we note as the rigorous alternative.
